# 👋 Hi there, I'm Gh0stbasta

### ☁️ Cloud Solution Architect | Infrastructure as Code | Automation | FinOps | AI

I am a **Cloud Solution Architect** with a passion for **Cloud, Infrastructure as Code, Automation, FinOps and creating measurable Business Value through technology**.

I like turning architecture into something tangible: infrastructure that can be deployed, tested, changed and reproduced through code.

My approach is provider- and tool-agnostic. Whether I'm working with AWS, STACKIT, Kubernetes, Terraform, GitHub Actions or GitLab CI, I focus on the underlying architecture, automation patterns and operational requirements rather than individual products.

I use the same engineering mindset for **enterprise cloud platforms and production-oriented architectures** as I do for my own small experiments and Proofs of Concept:

> **Understand the problem → design the architecture → automate it → measure it → improve it.**

AI is part of that workflow as well. I use tools such as Claude Code, GitHub Copilot and LLM-based workflows as engineering multipliers for research, implementation, architecture and automation.
